PyFDA Web

Free, installation-free online digital signal processing (DSP) application for designing, analyzing, and simulating digital IIR and FIR filters locally in your browser.

Filter Design Quick Start
  1. Select Response Type: Choose Lowpass (LP), Highpass (HP), Bandpass (BP), Bandstop (BS), or Allpass (AP).
  2. Select Filter Family: Choose Infinite Impulse Response (IIR) or Finite Impulse Response (FIR).
  3. Choose Design Method: Select Butterworth, Chebyshev, Elliptic, Bessel, Windowed FIR, or Equiripple.
  4. Configure Specifications: Set sampling rate (fs), corner frequencies (fpb, fsb), and allowable ripple/attenuation (Apb, Asb).
  5. Design & Analyze: Click Design Filter to compute coefficients and explore interactive frequency, pole-zero, and transient plots.
Filter Algorithms & Methods
IIR (Infinite Impulse Response):
  • Butterworth: Maximally flat passband magnitude with monotonic roll-off. No passband ripple.
  • Chebyshev Type I: Equiripple passband with sharper transition roll-off into monotonic stopband.
  • Chebyshev Type II: Monotonic passband with equiripple stopband attenuation.
  • Elliptic (Cauer): Equiripple in both passband and stopband; achieves steepest cutoff for a given order.
  • Bessel / Thomson: Maximally flat group delay with linear phase, preserving transient pulse fidelity.
FIR (Finite Impulse Response):
  • Windowed FIR (firwin): Linear-phase FIR using Hamming, Hann, Blackman, Bartlett, Kaiser, or Flat-top windows.
  • Equiripple (Parks-McClellan / Remez): Optimal Chebyshev minimax approximation across design bands.
  • Moving Average: Linear smoothing filter with uniform tap coefficients.
  • Least-Squares (firls): Weighted least-squares error minimization.
Interactive Analysis Tools
  • Frequency Response: Magnitude in dB, linear voltage, or power; phase unwrapped or wrapped into [-π, π].
  • Group & Phase Delay: Frequency-dependent time delay in sample steps or milliseconds.
  • Poles & Zeros (z-plane): Complex roots plotted against the unit circle |z|=1 with automatic stability verification.
  • Time-Domain Transient: Unit impulse response h[n] and step response s[n].
  • Custom Stimulus: Real-time signal generator for evaluating custom mathematical waveforms.
  • 3D Complex Surface: Full 3D interactive rendering of |H(z)| across the complex z-plane.
Fixed-Point & Export Formats

Simulate hardware implementation constraints on FPGAs and DSP processors with configurable word lengths (total bits, integer QI, fractional QF), overflow modes (Saturation vs. Wrap), and quantization methods (Round, Floor, Fix, Ceil, Rint).

Export Formats:
  • NumPy binary archive (.npz)
  • Comma-Separated Values (.csv)
  • MATLAB Matrix (.mat)
  • JavaScript Object Notation (.json)
Frequently Asked Questions
What is PyFDA Web? PyFDA Web is a free, web-based digital filter design and signal processing tool that brings the functionality of the Python Filter Design Analysis tool directly into your browser without installation.
How does it run Python algorithms in the browser? All signal processing calculations execute 100% locally on your computer using Pyodide (Python compiled to WebAssembly) with native NumPy and SciPy libraries, ensuring zero server latency and complete data privacy.
What digital filter types can I design? You can design Lowpass, Highpass, Bandpass, Bandstop, and Allpass filters using either IIR methods (Butterworth, Chebyshev I & II, Elliptic, Bessel) or FIR methods (Windowed, Equiripple, Moving Average, Least-Squares).
Can I export filter coefficients to MATLAB or Python? Yes, designed coefficients can be exported directly to NumPy (.npz), MATLAB (.mat), CSV (.csv), and JSON formats or copied to your clipboard.
